Frequently asked questions

How long does delivery take?

Most bundles arrive in a few minutes. But delivery comes from the network, not from us. When a network is congested (MTN is often) an order can take hours. We show each network’s live status, we watch every order through to delivery and step in by hand when one stalls, and you can track yours at any time. A slow order is not a failed order, so it is not refunded while it is still queued. If an order never reaches your number, we refund it — see the refund policy.

Can I send data to someone else's number?

Yes. Enter any valid beneficiary number when you order.

I entered the wrong number. Can you reverse it?

No. Data sent to a wrong, inactive or newly-activated number is not refundable or reversible. The network treats it the same way. Please double-check the number before you pay.

Is every network eligible?

No. Shared broadband/Turbonet SIM cards and some special SIM types are not eligible for data bundles. If in doubt, send us a WhatsApp first.

Do prefixes always match the network?

No. When a number is ported to another network it keeps its old prefix. Check the bundle's network, not just the prefix, and use the confirmation step before paying.

How do I check my order?

Use the “Track order” button. Enter your order reference and the last 4 digits of the beneficiary number.
