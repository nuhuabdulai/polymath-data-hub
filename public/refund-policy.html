Refund Policy

Last updated 26 Sep 2026

When we refund

  • Supplier failed to deliver and order status is Failed, wallet credited or Paystack refunded within 24h. This is also the limit our own supplier works to, so please report anything wrong with an order the same day. A delayed order is not a failed order: while the network is still queuing your bundle we do not refund it, because the data can and will still arrive. We watch every order and step in by hand if one stalls.
  • Duplicate payment, refunded in full.

When we don't refund

  • Wrong beneficiary number entered by customer (see confirmation step).
  • Ineligible SIM: agent, merchant or EVD SIM; Turbonet, broadband or WiFi-router; blacklisted, roaming or inactive SIM; a SIM with borrow credit or borrowed data; a number on the wrong network for the bundle; or a wrong number. Ask us before buying if you are unsure.
  • A second order for the same number at the same time. One of them can be rejected at the network with no refund, so please wait for the first to complete.
  • Ported numbers: prefix does not guarantee network. Check before paying.

How to request

Message us on WhatsApp with order ref and last 4 digits of beneficiary number. We track every order as Pending / Processing / Delivered / Failed.
